# Known Issues

Эти проблемы зафиксированы и требуют отдельного цикла доработки и QA.

1. Потенциальный цикл обновления `useEffect` на странице `/bookings/new` в отдельных сценариях инициализации формы.
2. Возможность сохранить пересекающиеся бронирования для одной квартиры при race-condition между клиентскими проверками.
3. В календаре занятые даты пока отображаются не как полноценно недоступные красные дни внутри стандартного date picker.

Примечание: текущая логика уже содержит частичную защиту, но требуется дополнительная верификация в рамках отдельного этапа стабилизации.
